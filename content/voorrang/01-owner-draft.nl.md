## Bestuurders en weggebruikers

Onderscheid maken tussen bestuurders en weggebruikers is een belangrijke deel in gebruik van de weg, omdat voor beide soorten andere regels gelden

1. Bestuurders - alle weggebruikers BEHALVE voetgangers

Voorbeeld :

- Iemand die op de trottoir loopt met een fiets AAN DE HAND is een weggebruiker, maar geen BESTUURDER
- Iemand die op een fiets rijdt op de FIETSPAD is wel een bestuurder.

## Hoe begrijp je of je een gelijkwaardige kruispunt nadeert?

- Er is geen stoplichten, tekens of andere voorrangs iets wat voorrang bepaalt

## Aan wie moet je voorrang verlenen op een gelijkwaardig kruispunt als je op een bromfiets rijdt?

- Op gelijkwaardige kruispunten verleen je voorrang aan BESTUURDERS van recht ( hier ook een plaatje )

Er gelden wel 2 uitzonderingen:

1. BESTUURDERS op een onverharde weg verlenen voorrang aan bestuurders op een verharde weg ( Hier moet echt een plaatje bij )
2. Bestuurders verlenen voorrang aan bestuurders van een tram ( hier ook een plaatje )

Een voorbeeld : Je nadeert een gelijkwaardige kruispunt, rechts van je komt een fietser. Je moet voorrang verlenen aan de fietser, omdat die van rechts komt. ( ook een plaatje )
