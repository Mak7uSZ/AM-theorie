# Milestone 1: ручная приёмка в Roblox Studio

Статус всех пунктов: **не проверено в Studio**. Ставьте отметки только после реального запуска.

- [ ] F5 → меню; до Spelen персонаж не перемещается. Spelen → свободная ходьба.
- [ ] Оранжевый круг до завершения книги объясняет блокировку и не запускает тренировку.
- [ ] Выйти с синего круга примерно через 3 секунды → таймер сброшен, книга не открывается после ожидания снаружи.
- [ ] Простоять полные 5 секунд → одна книга. Пока она открыта, повторного запуска нет.
- [ ] Sluiten на первой/второй странице → тренировочный круг остаётся заблокирован.
- [ ] Vorige/Volgende работают; завершение доступно только на последней странице.
- [ ] Theorie afronden → тренировка доступна; Voortgang честно показывает прочитанную теорию без отметки «тема сдана».
- [ ] Выйти с тренировочного круга до 5 секунд → сцена не начинается.
- [ ] Полные 5 секунд → один пролёт камеры с движущимся трамваем → один вопрос.
- [ ] Выбрать второй ответ → «Kennis: goed». После возврата повторить и выбрать первый/третий → «nog oefenen».
- [ ] На старте действия ничего не нажимать → остановка вдали от линии не засчитывается; через 25 секунд неудача.
- [ ] Подъехать и остановиться целиком в жёлтой зоне на секунду → успешная **акция** независимо от результата ответа.
- [ ] Проехать передним краем блока за линию → неудачная акция, даже если ответ был правильный.
- [ ] Terug naar lobby → обычная камера, ходьба, нет старого окна или активной сцены. Можно повторить тренировку.
- [ ] Умереть/Reset Character во время книги/сцены → возрождение без застрявшей камеры и замороженного персонажа.
- [ ] Открыть Instellingen во время отсчёта → отсчёт отменяется. Изменение размера текста видно при следующем открытии книги.
- [ ] Stop → Play → теория снова не прочитана. Это ожидаемый session-only режим.
- [ ] На стене нет придуманных результатов.

## Два игрока

В Studio откройте инструменты тестирования и выберите локальный режим **Server & Clients** с **2 клиентами**, запустите тест (название команды зависит от раскладки Studio).

1. У первого игрока завершите книгу, у второго — нет. Второму тренировка недоступна.
2. Завершите книгу обоим, запустите обе тренировки. Площадки и трамваи разные; результаты одного не меняют другого.
3. Выйдите одним клиентом во время сцены: его площадка удаляется, другой продолжает.
4. Возродите персонажа во время сцены: управление и камера восстанавливаются.

## Проверки запросов

При проверке из клиентской Command Bar можно вручную отправить `game.ReplicatedStorage.PrototypeEvent:FireServer("Finish")` из лобби: теория не должна стать прочитанной. Аналогично `Answer` вне вопроса и `Drive` вне действия должны игнорироваться. Команды никогда не должны выдавать тему «пройдена» или сохранять очки.

Текущая защита — проверки типа, этапа, токена сцены и частоты запросов. Это прототип, не завершённая система защиты от эксплойтов.
