# Урок 5: вторая станция — Verkeerstekens

18 ноября 2026. Добавлена одна новая пара кругов: теория и тренировка для Verkeerstekens. Это небольшой следующий шаг, не реализация всех восьми разделов.

## Что теперь есть

| Станция | Круг теории | Круг тренировки |
| --- | --- | --- |
| Voorrang — ближе к месту появления | Синий, прежняя книга из 6 страниц | Оранжевый, прежние 3 дорожные сцены |
| Verkeerstekens — на следующем ряду, ближе к стене | Фиолетовый, 4 страницы B1/B2/B6/B7 | Зелёный, 4 карточки распознавания знаков |

На каждом круге нужно оставаться 5 непрерывных секунд. Выход или переход на другой круг начинает отсчёт заново. Для каждой тренировки нужно закончить **её собственную** книгу. Прочитанная Voorrang не открывает Verkeerstekens и наоборот.

Вторая станция доступна для чтения сразу: требование сдачи предыдущей полной темы пока не вводилось. Порог сдачи темы ещё не согласован; окончание четырёх карточек означает завершение упражнений, а не официальный статус «тема сдана».

Прогресс раздельный для каждой темы и игрока, хранится только в текущем подключении. В Voortgang видны прочитанные книги и лучший результат завершённой тренировочной серии. Возрождение персонажа сохраняет состояние, выход из сервера или Stop сбрасывает.

## Установка: полностью заменить три файла

1. В Studio нажмите **Stop**.
2. Откройте **ReplicatedStorage → TopicContent** (ModuleScript). Полностью замените текст содержимым `src/ReplicatedStorage/TopicContent.lua`.
3. Откройте **ServerScriptService → Boot** (Script). Полностью замените текст содержимым `src/ServerScriptService/Boot.server.lua`.
4. Откройте **StarterPlayer → StarterPlayerScripts → ClientController** (LocalScript). Полностью замените текст содержимым `src/StarterPlayerScripts/ClientController.client.lua`.
5. Сохраните проект и нажмите F5. Ничего нового вручную в Explorer создавать не нужно. Новые PNG загружать не требуется: схемы знаков строятся интерфейсом.

Обновите все три файла вместе: TopicContent теперь каталог из двух тем. Старый сервер или клиент не рассчитан на этот формат. Уже заполненные ID изображений Voorrang сохранены.

Во время Play сервер создаёт:

```text
Workspace
  AMPrototype
    TopicStations
      voorrang
        TheoryPad
        TrainingPad
      verkeerstekens
        TheoryPad
        TrainingPad
```

## Как проверить второй маршрут

1. Нажмите Spelen и пройдите к следующему ряду кругов. Сначала встаньте на зелёный: он должен объяснить, что нужно закончить книгу Verkeerstekens.
2. Встаньте на фиолетовый на 3 секунды, выйдите и подождите. Книга не должна открыться. Вернитесь и дождитесь полных 5 секунд.
3. Пролистайте B1 → B2 → B6 → B7. На последней странице нажмите Theorie afronden.
4. Теперь постойте на зелёном 5 секунд. Появится знак и четыре варианта его описания. Здесь тренировка идёт карточками, без дорожной катсцены.
5. Выберите вариант: сервер покажет результат и подпись к знаку. Opnieuw повторяет карточку, Volgend bord переходит дальше, Naar lobby / Terug naar lobby завершает упражнение.
6. Пройдите четыре карточки и откройте Voortgang. Лучший результат должен относиться к Verkeerstekens. В первой теме по-прежнему доступны её книга и три сцены.

Ответ засчитывается один раз на карточку. Повтор заменяет текущий ответ, не начисляет лишние баллы. «Следующая карточка» доступна после ответа. Две темы и два игрока могут работать независимо.

## Где что находится в коде

- **TopicContent** возвращает каталог: `order` задаёт порядок станций, `topics.voorrang` и `topics.verkeerstekens` содержат публичные страницы, источники и изображения/коды схем. Правильных индексов ответа здесь нет.
- **Boot** строит станции, хранит `topics[topicId]` для каждого игрока, выбирает книгу по кругу и проверяет ответы. `signCards` и ключи распознавания находятся только на сервере.
- **ClientController** рисует схемы B1/B2/B6/B7 и интерфейс, показывает раздельный прогресс, отправляет выбранный индекс с токеном сессии. Во второй тренировке нет балла за вождение и нет аварии при ошибке распознавания.

## Важное о новой теории

Пока это **draft**: точные короткие подписи к знакам из источника и места `[CONCEPT — OWNER TO WRITE]` для вашего объяснения. Это не готовая написанная за вас тема. Полная теория применения, исключения и конкретные действия на bromfiets будут вашим текстом.

Первичный источник — [RVV 1990, приложение 1](https://wetten.overheid.nl/BWBR0004825/#Bijlage1); [Rijksoverheid](https://www.rijksoverheid.nl/themas/verkeer-en-vervoer/wegen/vraag-en-antwoord/verkeersveiligheid/welke-verkeersborden-en-verkeersregels-gelden-in-nederland) направляет к нему как к перечню знаков. При подготовке сверены доступные официальные архивные подписи: [RVV, архивная редакция](https://wetten.overheid.nl/BWBR0004825/HoofdstukI/Artikel1/geldigheidsdatum_10-07-2013), [первоначальный Staatsblad 1990-459](https://zoek.officielebekendmakingen.nl/stb-1990-459.pdf). Текущая консолидированная редакция ещё требует проверки; `reviewed` не назначен. Геометрические рисунки — собственные учебные схемы, не сертифицированные макеты дорожных знаков.

Чтобы продолжить учиться через игру, откройте `TopicContent`, найдите `local verkeerstekens`, затем нужную страницу в `pages`. Меняйте только текст внутри `text = "..."`, сохраняя кавычки и обозначая перенос строки как `\n`. Можете сначала прислать текст в чат: после проверки вставим его вместе.

## Дополнительные проверки

- [ ] Прочитать только вторую книгу: первая тренировка остаётся закрытой для нового игрока.
- [ ] Прочитать только первую книгу: вторая тренировка остаётся закрытой.
- [ ] Поменять круг во время отсчёта: пять секунд не складываются между станциями.
- [ ] Закрыть книгу до последней страницы: соответствующая тренировка не открывается.
- [ ] Сделать ошибку и повторить карточку: итог не превышает число пройденных карточек.
- [ ] Вернуться, умереть или возродиться: персонаж не остаётся заморожен, старый интерфейс скрыт.
- [ ] В тесте с двумя клиентами один проходит дорожную сцену, другой — знаки; результаты не смешиваются.

В Output фильтр `[AM Theory]` показывает тему, ID вопроса, таймер и события `SignQuestion` / `SignResult`.
