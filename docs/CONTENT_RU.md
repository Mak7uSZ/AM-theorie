# Как будем работать с теорией

Автор нидерландской теории — владелец проекта. Voorrang помечен `CONCEPT`, `reviewStatus = "awaiting_review"`. Вторая станция Verkeerstekens пока `draft`: короткие подписи из источника и поля для авторского объяснения, плюс упражнение распознавания. Полная сверка текущей редакции источника ещё не завершена.

Первый авторский текст сохранён: [оригинал](../content/voorrang/01-owner-draft.nl.md), [согласованная редакция и источники](../content/voorrang/01-review.nl.md). По просьбе автора редакция включена в шесть страниц `TopicContent` со статусом `awaiting_review` и заметной пометкой CONCEPT. Иллюстрации сохранены в `assets/theory/voorrang`; для показа в Roblox нужны импорт и заполнение ID по [инструкции урока 2](LESSON_02_RU.md).

Для новой станции используйте [авторский шаблон B1/B2/B6/B7](../content/verkeersborden/01-owner-draft.nl.md) и [инструкцию урока 5](LESSON_05_RU.md). Схемы знаков рисуются кодом; подписи из RVV отделены от ещё не написанного объяснения владельца. Завершение черновой книги не означает юридическую проверку или освоение всей темы.

Для будущей страницы сначала выбираем первичный источник: [RVV 1990](https://wetten.overheid.nl/BWBR0004825/) для правил дорожного движения; актуальные материалы [CBR](https://www.cbr.nl/) — для структуры экзамена. Это ссылки для дальнейшей проверки; конкретная правовая норма в прототип пока не включена и не проверена.

Процесс:

1. Определяем конкретную тему и статью действующей редакции официального документа.
2. Вы пишете свой текст на нидерландском.
3. Проверяем утверждения, применимость к bromfiets/snorfiets, исключения и ясность формулировки по действующему официальному источнику.
4. Только после проверки меняем статус `draft → awaiting_review → reviewed` и сохраняем `sourceName`, `sourceUrl`, `article`.

Не заменяйте черновые страницы случайными ответами из тренажёров. Статус `reviewed` не означает официальную сертификацию CBR.
