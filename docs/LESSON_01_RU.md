# Итоги первого урока — 17 ноября 2026

Пользователь запустил прототип в Roblox Studio и сообщил: «всё работает в целом». На скриншоте видны лобби, круги и статус доступной тренировки. Полный чек-лист, особенно два клиента, пока отдельно не подтверждён.

По обратной связи подготовлены изменения:

- Подписи кругов ограничены размером в 3D и уменьшаются с расстоянием; максимум шрифта 18. Стена рекордов использует текст на поверхности вместо плавающей подписи.
- Текст интерфейса подстраивается под доступное место с ограничением максимального размера; обычный текст книги до 17, кнопки до 16, статус до 14. Верхний статус опущен ниже стандартного меню Roblox.
- В Output добавлены серверные события книги, таймеров, вопроса, выбранного ответа, результата, начала действия, газа/тормоза и возврата. Для остановки выводятся положение, скорость и время.
- Клиент пишет отправленные команды интерфейса и полученные события. Серверные логи показывают подтверждённые переходы; строка Request означает только запрос, а не успешное выполнение.
- Частые сигналы движения не печатаются каждый кадр: только изменения газа/тормоза. Таймер печатается раз в изменение секунды; неверные запросы ограничены по частоте диагностики.

## Как установить обновление

1. Нажмите **Stop**.
2. Полностью замените `ServerScriptService/Boot` содержимым `src/ServerScriptService/Boot.server.lua`.
3. Полностью замените `StarterPlayer/StarterPlayerScripts/ClientController` содержимым `src/StarterPlayerScripts/ClientController.client.lua`.
4. `TopicContent` менять не нужно. Нажмите F5, проверьте размеры надписей и один полный цикл книги/вопроса/остановки. Для Output включите контексты **Server** и **Client**, фильтр текста: `[AM Theory]`.
5. После Stop сохраните локальную копию place через **File → Download a Copy**.

Пример серверного лога:

```text
[AM Theory][Server][Player:123][phase=book][session=0] Send:Book page=2/3
[AM Theory][Server][Player:123][phase=answered][session=1] Send:AnswerFeedback question=tram_demo_01 correct=true
```

Правильный ответ не выводится до выбора игрока. Для отключения подробных логов установите `DEBUG_LOGS = false` отдельно в Boot и ClientController.

Эти изменения прошли проверку синтаксиса Luau; обновлённая версия в Studio ещё не проверена. На следующем уроке начните с проверки нового размера надписей и логов, затем завершите ручную приёмку Milestone 1. Milestone 2 пока не начинали.

Git хранит исходники; Studio не обновляет их автоматически. После урока подключён удалённый репозиторий https://github.com/Mak7uSZ/AM-theorie.
