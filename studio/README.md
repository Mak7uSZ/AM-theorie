# Локальный Roblox place

Сохраните сюда `AMTheoryPrototype.rbxl` через **File → Download a Copy** в Studio. `.rbxl` исключён из Git. Для восстановления установите скрипты и модули на Baseplate. [Инструкция для Studio](../docs/STUDIO_SETUP_RU.md).

Позже, когда появятся созданные вручную модели и карта, отдельно выберем способ версионирования этих ресурсов. Пока не храните единственную копию ручных объектов в игнорируемом place.
