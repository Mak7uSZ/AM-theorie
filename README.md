# Roblox AM Theory Simulator

Прототип с двумя станциями: **Voorrang** (авторская книга и три дорожные сцены) и **Verkeerstekens** (четыре проверенные страницы B1/B2/B6/B7 и четыре карточки распознавания). У каждой собственные круги теории/тренировки с таймером 5 секунд и отдельный прогресс. В Voorrang остаются ручной подъезд от первого лица и автоматические последствия решения.

**Начните с [пошаговой установки](docs/STUDIO_SETUP_RU.md).** Затем выполните [проверки](docs/ACCEPTANCE_RU.md).

**Текущее обновление добавляет авторский текст B1/B2/B6/B7.** Если в Studio уже есть обе станции, обновите `TopicContent` и `ClientController`. Схемы знаков рисуются кодом. [Установка и проверка второй станции](docs/LESSON_05_RU.md).

**Учимся AM, создавая игру.** Восемь разделов выбраны владельцем по присланным примерам. В план входят собственные задания с числовым ответом, выбором участника и порядком проезда, а также повороты, сцепление и физика безопасного движения. Полнота относительно актуальных требований CBR ещё не проверена. Экзамен пока не назначен. [Карта 76 подтем](docs/AM_TOPIC_MAP_RU.md) · [План по 4 подтемы в неделю](docs/AM_STUDY_PLAN_RU.md) · [Форматы заданий](docs/CURRICULUM_REFERENCE_RU.md).

[Итоги первого урока и установка обновления размеров/логов](docs/LESSON_01_RU.md). Пользователь подтвердил общий запуск в Studio; полный чек-лист ещё не закрыт.

START_HERE.md                                         # исходная записка из handoff

Файлы `.lua` вручную копируются в Studio. Сами по себе они туда не загружаются. Rojo, плагины, сторонние модели и зависимости не нужны.

Мир и UI строятся при Play и исчезают после Stop — это ожидаемо. Сохраняется исходный код, создающий их.

## Границы прототипа

- Сервер проверяет таймер, порядок чтения страниц, ручной подъезд, момент вопроса и ответы, затем выбирает автоматическое продолжение. Клиент передаёт намерения, а не баллы.
- Положение аватара проверяется сервером; полноценная защита от телепортации эксплойтами ещё не реализована.
- У каждого игрока отдельная тренировочная площадка. Проверка двумя клиентами включена в ручной чек-лист.
- Реалистичного скутера пока нет: используется упрощённый транспорт с рулём и камерой на уровне водителя; аватар ожидает рядом.
- Voorrang отмечен `awaiting_review`. Четыре страницы Verkeerstekens сверены с применимой редакцией RVV и имеют статус `reviewed`.
- Оценивается решение. После выбора движение автоматическое: ожидание и безопасный проезд либо постановочное столкновение. Баллы за ручное вождение не выдаются.
- Постоянного сохранения, 10 сцен, экзамена, разблокировки следующих тем и настоящих рекордов ещё нет. Они относятся к следующим milestones.
- Прогресс каждой темы доступен только в текущем подключении. Смерть персонажа сохраняет прочитанную теорию, выход/Stop сбрасывает её. Темы пока читаются независимо; тренировку открывает только её собственная книга. Завершение серии не является статусом «тема сдана».
- Целевая проверка сейчас — ПК. Сенсорные кнопки предусмотрены, мобильная адаптация ещё не проверена.

## Проверка

17 ноября 2026: все три исходных файла успешно скомпилированы официальным `luau-compile 0.747` (`--null`); проверка `git diff --check` не обнаружила проблем форматирования. Компилятор использовался отдельно, устанавливать его для запуска прототипа не нужно.

Luau-компиляция проверяет синтаксис, но не поведение объектов Roblox. Сервер прошёл 284 автоматические проверки (`tests/run-server-tests.ps1`), клиент — 76 проверок состояния и геометрии UI (`tests/run-client-tests.ps1`). Тесты исполняют настоящие исходники на подменённых объектах движка. Пользователь ранее запустил версию с первым лицом. **Новую станцию Verkeerstekens и схемы знаков ещё нужно визуально проверить в Studio.**

## Git и разные ПК

Основная ветка — `main`; изменения удобно делать в `codex/<название>`. См. [настройку удалённого репозитория и работу на двух ПК](docs/GIT_WORKFLOW_RU.md).

Удалённый репозиторий: [Mak7uSZ/AM-theorie](https://github.com/Mak7uSZ/AM-theorie). Между ПК используйте `push`/`pull`; Studio не синхронизирует `.lua`-файлы автоматически.
