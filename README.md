# Roblox AM Theory Simulator

Первый прототип Milestone 0–1: меню → 3D-лобби → два соседних круга по 5 секунд → книга → одна сцена с трамваем → остановка учебного блока → результат → лобби.

**Начните с [пошаговой установки](docs/STUDIO_SETUP_RU.md).** Затем выполните [проверки](docs/ACCEPTANCE_RU.md).

## Файлы

```text
src/
  ReplicatedStorage/TopicContent.lua                  # ModuleScript: страницы книги
  ServerScriptService/Boot.server.lua                 # Script: мир, состояния, проверки
  StarterPlayerScripts/ClientController.client.lua    # LocalScript: интерфейс, камера, ввод
docs/
  STUDIO_SETUP_RU.md
  ACCEPTANCE_RU.md
  GIT_WORKFLOW_RU.md
  CONTENT_RU.md
studio/README.md                                      # куда сохранять локальный place
AGENTS.md                                             # инструкции из handoff
CODEX_MASTER_BRIEF.md                                 # исходное ТЗ
START_HERE.md                                         # исходная записка из handoff
```

Файлы `.lua` вручную копируются в Studio. Сами по себе они туда не загружаются. Rojo, плагины, сторонние модели и зависимости не нужны.

Мир и UI строятся при Play и исчезают после Stop — это ожидаемо. Сохраняется исходный код, создающий их.

## Границы прототипа

- Сервер проверяет таймер, порядок чтения страниц, ответы, движение учебного блока и остановку. Клиент передаёт намерения, а не баллы.
- Положение аватара проверяется сервером; полноценная защита от телепортации эксплойтами ещё не реализована.
- У каждого игрока отдельная тренировочная площадка. Проверка двумя клиентами включена в ручной чек-лист.
- Настоящего скутера пока нет: движется серверный учебный блок, аватар ожидает рядом.
- Вопрос проверяет понимание инструкции демо, а не юридическое правило приоритета трамвая. Тексты — явный `draft`, без утверждения о проверке ПДД.
- Постоянного сохранения, 10 сцен, экзамена, разблокировки следующих тем и настоящих рекордов ещё нет. Они относятся к следующим milestones.
- Прогресс доступен только в текущем подключении. Смерть персонажа сохраняет прочитанную теорию, выход/Stop сбрасывает её.
- Целевая проверка сейчас — ПК. Сенсорные кнопки предусмотрены, мобильная адаптация ещё не проверена.

## Проверка

17 ноября 2026: все три исходных файла успешно скомпилированы официальным `luau-compile 0.747` (`--null`); проверка `git diff --check` не обнаружила проблем форматирования. Компилятор использовался отдельно, устанавливать его для запуска прототипа не нужно.

Luau-компиляция проверяет синтаксис, но не поведение объектов Roblox. **В Roblox Studio этот прототип пока не запускался. Milestone 1 нельзя считать принятым до выполнения ручных тестов.**

## Git и разные ПК

Основная ветка — `main`; изменения удобно делать в `codex/<название>`. См. [настройку удалённого репозитория и работу на двух ПК](docs/GIT_WORKFLOW_RU.md).

Локальная папка `.git` не синхронизирует компьютеры сама. Нужен GitHub/GitLab remote и `push`/`pull`. Удалённый репозиторий пока не подключён.
